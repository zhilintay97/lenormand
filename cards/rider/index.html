骑士

骑士的牌义

骑士是雷诺曼牌组的第一张，也是最直接关联「移动」与「沟通」的一张。 它出现时，往往意味着有消息、有讯息，或有什么东西很快就要到了—— 一通电话、一封邮件、一次登门，或是你一直在等的那个说法。 它极少指向缓慢或沉重的事，气息是轻的、快的、当下的。

除了消息，骑士也代表年轻男性、少年气，以及身体层面的移动： 运动的人、送货、开车或坐飞机的行程。在解读中，这张牌几乎不单独成立—— 它的含义几乎完全由旁边那张牌决定。骑士只告诉你「有东西在路上」， 至于是什么，要看它身边的牌。

骑士与感情

在感情里，骑士常常意味着新的接触：第一条消息、一次久等的回复、一句约见面的邀请。 对于有伴侣的人，它可以标记一段快速的进展——伴侣那边传来的消息、一个正在赶来的浪漫举动， 或是沉寂一阵后重新开始的流动。对单身的人，它多半是一位年轻的追求者， 或是一场比预期来得更早的偶遇。无论指向哪一边，那股能量都是轻盈而即刻的。

骑士与事业

在工作上，骑士指向即将进来的沟通：一份录用通知、一封回信、一件悬而未决之事的最新进展。 它也可以表示节奏很快的项目、新客户上门，或是消息在团队内部传开。 这张牌同样代表更年轻的同事、配送，以及与交通运输相关的工作。 如果你正在等一份工作、一纸合同或一个决定的答复，骑士说：它在路上了。

骑士的建议

留意你收到的讯息，对到来的一切保持开放。骑士劝人快一点—— 接起那通电话，回掉那封邮件，趁机会还在就去赴那场会面。 它也提示你可能需要由你来传达消息，而且不要拖。 重要的沟通，别压在手里。

骑士的组合牌义

雷诺曼的牌很少单独说话——骑士尤其会追问一句「关于什么的消息？」， 而答案永远来自它旁边那张牌。以下按牌序，列出骑士与其余 35 张牌的读法：

  • 骑士 + 幸运草 迅速传来的好消息，一点小小的运气正在到来。
  • 骑士 + 船 来自远方的消息，从异地抵达的人或事，与旅行有关的通知。
  • 骑士 + 房屋 关于家庭或亲人的消息，门口来了访客。
  • 骑士 + 树 姗姗来迟的消息，往往与健康有关。
  • 骑士 + 云 含糊不清的消息，对某个讯息心存疑虑。
  • 骑士 + 蛇 麻烦的消息、流言，或一则复杂难解的讯息。
  • 骑士 + 棺材 坏消息，关于结束或失去的通知。
  • 骑士 + 花束 一份愉快的邀约，善意的、受欢迎的消息。
  • 骑士 + 镰刀 突然、紧急，甚至令人震动的消息。
  • 骑士 + 鞭子 争执中的往来，反复或激烈的沟通。
  • 骑士 + 飞鸟 电话、闲谈，一来一往的对话。
  • 骑士 + 孩童 关于孩子的消息，一个崭新的开始。
  • 骑士 + 狐狸 不实或带有欺瞒的消息，一则误导人的讯息。
  • 骑士 + 熊 来自上位者的消息，牵涉某位有分量人物的通知。
  • 骑士 + 星星 带来希望的消息，线上的讯息，公开的传播。
  • 骑士 + 鹳鸟 关于变动、搬迁的消息，或有孩子即将到来。
  • 骑士 + 狗 朋友传来的消息，可信赖的讯息。
  • 骑士 + 高塔 官方消息，正式或来自机构的通知。
  • 骑士 + 花园 公开场合的消息，群发的通知或社交层面的宣布。
  • 骑士 + 高山 延迟的消息，被卡住的沟通，讯息遇到阻碍。
  • 骑士 + 十字路口 关于某个决定的消息，选项正在浮现。
  • 骑士 + 老鼠 丢失的讯息，消息淡去，或始终没能真正送达。
  • 骑士 + 心 关于爱的消息，一则表达情意的讯息。
  • 骑士 + 戒指 关于承诺的消息，一份提议或订婚的通知。
  • 骑士 + 书 尚未公开的消息，来自研究或学习方面的进展。
  • 骑士 + 信 一则书面讯息，一封邮件，一份即将送达的文件。
  • 骑士 + 男人 来自或关于某位男性的消息，往往由男性传话。
  • 骑士 + 女人 来自或关于某位女性的消息，往往由女性传话。
  • 骑士 + 百合 平和的消息，家中的沟通，常来自一位年长的男性。
  • 骑士 + 太阳 令人高兴的消息，成功正在路上。
  • 骑士 + 月亮 触动情绪的消息，与名声或认可有关的通知。
  • 骑士 + 钥匙 重要的消息，一则关键的讯息或突破。
  • 骑士 + 鱼 关于钱的消息，财务或生意上的往来。
  • 骑士 + 锚 关于工作的消息，一则带来稳定感的讯息。
  • 骑士 + 十字架 沉重的消息，有人正在传达一份负担。

图像象征

传统图像是一位年轻骑手，纵马疾驰过开阔的原野—— 这是反复出现在欧洲民间图像里的信使形象。他带来的是下一张牌所描述的内容。 马是那台引擎：速度、活力、动起来的身体。 现代读者常用今天的对应物替换它——手机弹出的提示、上门的快递、停在门口的车。 不变的那一部分，是「抵达」。
