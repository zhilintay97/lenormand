如何提出雷诺曼问题

✦

你怎么问，就会得到怎样的解读。雷诺曼是一副务实、贴近具体处境的牌——问题问得具体、明确、框架得当，它才能发挥所长。

问题决定解读

雷诺曼对问题的措辞很敏感。问题含糊，解读也含糊；问题锋利，解读跟着锋利。这不是玄学，任何工具都是如此：电钻对准哪里，就在哪里钻孔；牌回应的，也只是你实际问出口的那句话。

从历史上看，雷诺曼是占卜师用的牌，处理的是生活、工作、金钱、家庭、感情这类日常问题。问题贴近这个传统，它就最好用。

具体胜过抽象

具体的处境类问题，雷诺曼应付起来毫不费力；抽象的灵性问题却让它为难。「明天和上司谈话，我需要知道什么？」这样的问题读起来很顺；「我的灵魂使命是什么？」抽出来的牌往往单薄、笼统。这副牌本来就不是为灵魂使命设计的，它擅长的是真实生活的种种纹理。

如果你的问题显得太抽象，不妨想想它背后到底指向哪个具体处境。底下通常压着一个明确的决定、一段关系或一件事。问那个。

开放式胜过是非题

雷诺曼也能回答是非题，但这类解读往往最不令人满意。牌想要描述，而不是裁决。把是非题改写成开放式问题，答案几乎总会更丰富：

  • 我会得到这份工作吗？ → 围绕我这次求职的是什么样的能量？
  • 我们会复合吗？ → 眼下我们之间横着什么？
  • 我该搬去柏林吗？ → 关于搬去柏林，牌想说什么？
  • 他出轨了吗？ → 这段关系现在到底是什么状况？

每个开放版本都在邀请牌去描述一个处境，而不是给出非此即彼的判决。而这些描述，通常本来就比一句判决更有用。

精确胜过笼统

问题越精确，牌越好读。「我的工作运势如何？」勉强可以；「下周要向上司提案的那个项目，眼下是什么样的能量？」更好。精确会收窄牌的焦点，符号也随之清晰起来。

如果问题涵盖的范围太大（「我整个感情生活到底怎么了？」），就把它拆开。一次只问一段关系、一个决定、一件事。几次简短的解读，胜过一次面面俱到的。

给问题加上时间范围

问「未来」的雷诺曼解读往往浑浊；加上时间范围，画面立刻清晰。「接下来一个月会发生什么？」读起来干净利落，「接下来会发生什么？」则一片模糊。好用的时间范围有：接下来一周、接下来一个月、接下来三个月、接下来一年。选定一个，牌就会在那个窗口里回应你。

好用的提问句式

  • 关于 [X]，我需要知道什么？
  • 围绕 [X] 的是什么样的能量？
  • 接下来[时间范围]里，[某个生活领域]会发生什么？
  • 眼下[我]和[某人]之间横着什么？
  • 关于[某个决定 / 某个处境]，我需要看清什么？
  • [X] 会怎样发展？

不好用的提问句式

  • 是非题（答案常常很单薄）。
  • 灵魂使命、人生目的、灵性道路一类的问题（雷诺曼不是为它们设计的）。
  • 追问他人内心状态的问题（「他在想什么？」）——雷诺曼能描述行为，却很少读得准心思。
  • 你其实已经替自己回答过的问题（你会挑对自己有利的牌来看）。
  • 在愤怒或恐慌中问出的问题（注意力不在，解读也会照出这一点）。

把问坏的问题重新问一遍

如果第一次问得不对劲，换个问法再问就是了。没有哪条规矩说你只有一次机会。更好的办法是：想想在这个问题底下，你真正想弄清楚的是什么。「他会回我消息吗？」通常意味着「他对我这边是什么状况？」或者「这段联结正在怎样发展？」——后面这两个，才是牌能回答的真问题。
